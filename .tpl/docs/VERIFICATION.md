# 验证

检查命令由 project.json 声明。pnpm typecheck、pnpm lint、pnpm test、pnpm build。服务默认 43292，HTTP 首页应为 200，未知路径应为 404。

检查中文与英文的产品图库、语言切换、菜单键盘操作、FAQ、联系和订阅表单提示互相独立。PC 1440×1000、平板 834×1180、手机 390×844，并检查 320px 宽屏。

本参考来源只有静态图片，没有可对照的原站动态行为。动效为自主设计，包含首屏缩放、文字入场、卡片错峰、悬停与按压、图库切换及菜单原生开关；减少动态效果时关闭运动。

格式检查依赖真实 gitUrl。实际应用检查结果与源码摘要见 reports/；历史报告仅适用于其记录的源码。
