# Sonora 模板使用说明

先阅读 template.json、project.json，然后阅读 docs/ARCHITECTURE.md、CUSTOMIZATION.md、VERIFICATION.md、LICENSE.md。

能力：双语品牌展示、四图产品图库、三篇文章、响应式导航、原生 FAQ、本地演示表单。限制：无真实商品销售、账户、发送、分析或持久化。所有产品与品牌内容是概念演示。

Node/pnpm 精确版本、依赖锁、安装和运行命令见根 README 与 project.json。无需私密环境变量；PORT 为非秘密服务端变量。运行素材本地托管。Ctrl+C 结束自行启动的服务，不停止其他项目进程。

源码可按 CUSTOMIZATION.md 修改并运行对应检查。当前无远端 Git 地址，不能将格式检查通过作为本次交付声明。
