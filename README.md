# Sonora

自然材质与柔和日光构成的双语家居音响品牌模板。13 个页面、26 条中英文路径，包含产品图库、声音与设计介绍、三篇生活日志、联系、FAQ 和政策页。图片为 AI 生成概念素材。

首次阅读 .tpl/README.md、.tpl/template.json、.tpl/project.json。

Node 24.16.0，pnpm 12.10.1。安装：pnpm install --frozen-lockfile；启动：pnpm dev，默认 http://localhost:43292；英文 /en。终端 Ctrl+C 停止。生产预览先 pnpm build，再 pnpm start。构建在本地 Linux 文件系统执行。

验证：pnpm typecheck、pnpm lint、pnpm test、pnpm build。修改入口见 .tpl/docs/CUSTOMIZATION.md。表单只进行浏览器本地校验，不发送、不保存。无后端、账号、支付或持久化。

源码仓库：https://github.com/weelume/sonora-template 。
